## 下一步验证提示

1. 加载与 CeruMusic 中相同的插件，分别搜索 `kw` 和 `tx` 歌曲。
2. 播放搜索结果并进入歌词页，检查插件歌词是否显示。
3. 进入发现页，依次切换网易云、酷狗、酷我、QQ、咪咕，检查热门歌单列表。
4. 进入搜索页，切换“全部”和单个平台，输入关键词，检查搜索建议是否出现。

## 2026-06-02 逐字歌词验证提示

1. 使用带 YRC/QRC/KRC 逐字歌词的插件歌曲播放，进入歌词页确认当前词有亮色遮罩推进、轻微上浮放大，当前行会自动居中。
2. 手动拖动歌词列表，确认自动滚动暂停约 3 秒，点击右侧播放按钮可跳转到中线歌词时间。
3. 播放只有普通 LRC 的歌曲，确认仍能显示整行歌词、翻译、罗马音，并且不会出现逐字时间错位。
4. 如果 tx/QQ 源后续能拿到 QRC `LyricContent`，优先检查 `parseLyricAuto` 是否识别为逐字格式，并确认词时间已经转换为播放绝对时间。

## 2026-06-02 逐字歌词丝滑度验证提示

1. 播放带逐字歌词的歌曲，观察当前词高亮是否连续推进，不应再每 200ms 跳一格。
2. 快速切换歌词行时，确认当前行仍在 500ms 内平滑居中，非当前行只有缩放、透明度和可选模糊变化。
3. 开启/关闭歌词模糊设置分别测试；如果低端设备仍卡顿，优先关闭模糊，因为 Flutter 的 `ImageFiltered.blur` 比 Web CSS filter 更重。
4. 若后续继续优化，应优先接入 Flutter Performance Overlay 或 DevTools frame chart，确认 raster/UI thread 是否稳定低于 16.7ms。

## 2026-06-02 逐字歌词未启动验证提示

1. 使用会返回 `lxlyric/yrc/krc/qrc/lrcx/ttml` 字段的插件歌曲播放，进入歌词页确认日志中 `hasYrc=true`。
2. 如果插件同时返回普通 `lyric/lrc` 和逐字 `lxlyric/crlyric`，应优先显示逐字动画，而不是整行普通歌词动画。
3. 使用只有普通 LRC 的歌曲验证仍显示普通歌词，不应误判为逐字。
4. 若某首歌仍不启动逐字，记录插件 `getLyric` 原始返回 JSON 字段名，优先补充 `PluginHost._parseLyricBundle` 的字段别名。

## 2026-06-02 逐字歌词修复后验证提示

1. 使用网易云 `wy` 播放确认有 YRC 的歌曲，进入歌词页后应显示逐字高亮推进，而不是整行普通歌词动画。
2. 使用 QQ/tx 源播放确认有 QRC 的歌曲，优先检查日志中的 `hasYrc=true`，并确认歌词行按词推进。
3. 如果 tx 搜索结果同时带 `songmid` 和数字 `songId/songid`，应优先用数字 ID 尝试 QRC；普通 LRC 只能作为最后兜底。
4. 播放逐字歌词时观察当前词高亮是否连续，不应再出现固定 200ms 一跳的卡顿；如低端设备仍卡，优先关闭歌词模糊再测 raster 帧耗时。

## 追加验证提示

1. 除原始 `[start,duration]` YRC/QRC 外，也要用 `[mm:ss.xxx](start,duration,0)字` 形式验证一次，确认不会被识别后解析为空。
2. 若 tx 仍未进入逐字模式，优先打印最终进入 `parseLyricAuto` 的 `crlyric/lrc` 前 3 行，检查是否存在词级 `(start,duration,0)` 标签。
